GOODBYE GOTH v8.2 - COMBAT OLLY WALK TEST

CHANGES
- Added an eight-frame side-on Olly combat walk cycle using the latest supplied poses.
- Walk order: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8 -> loop.
- The assets face LEFT; the combat renderer flips them automatically for RIGHT-facing movement.
- Walking animation starts when horizontal movement begins and returns to the normal combat idle when movement stops.
- Punch, Heavy Attack, jump, dodge and hurt states are not interrupted by the walk loop.
- Map Olly movement and directional poses are unchanged.
- Zombie Goth art, AI, damage, timing, collision and difficulty are unchanged from v8.1.

ART WORKFLOW
Character design -> pose reference -> consistent directional/side profile -> dedicated animation software -> export frames -> integrate into game.

IMPORTANT
The current eight poses are a candidate combat walk cycle. They can be reduced, reordered or expanded after playtesting.
