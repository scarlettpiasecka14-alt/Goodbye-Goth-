# Goodbye Goth v4.7.2

Canonical Level 1 icon assets are now explicit and role-based:
- assets/icons/relationship-challenge.png = the user-supplied puzzle-piece sprite. This icon always represents the relationship challenge on every level.
- assets/icons/princess-question.png = the user-supplied gothic-heart sprite. This icon always represents the Princess Question on every level.

The activity behind each role is level-specific through LEVEL_ACTIVITY_DATA. Level 1 remains Would You? + the Princess Question. Level 2 is registered as Bathroom Burrito + Chaos Fairy Goth question.

No map, save/load, movement, camera, or menu changes are included in this patch.
