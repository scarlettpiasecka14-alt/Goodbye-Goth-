# Goodbye Goth v0.8

## This pass
Animation-only pass for Level 1 exploration. No combat, puzzle, relationship, loading screen, or map logic was intentionally changed.

## Animation changes
- Replaced the old simple geometric Olly exploration drawing with a chunky hand-drawn/pixel-cartoon character.
- Added clearer curly hair, face, beard, The Weeknd shirt, olive cargo trousers, shoes, bow, arms and legs.
- Added a small walking cycle with alternating legs/arms and body bob.
- Added movement direction tracking so Olly's walk animation follows the last movement direction.
- Kept the approved loading screen and all other game systems intact.

## Next
After this is tested, fix combat as a separate pass. Do not combine unrelated systems into the same patch.
