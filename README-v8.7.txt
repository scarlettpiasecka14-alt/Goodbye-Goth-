GOODBYE GOTH v8.7
Zombie walk/death timing + ground alignment patch

Changes from v8.6:
- Zombie combat walk animation cycle is ~15% faster (150ms -> 128ms per frame).
- Zombie movement/chase speed is unchanged.
- Zombie death collapse frames are slowed by ~15%.
- Final death pose is held for 5000ms (5 seconds) so the defeat is unmistakable.
- Death frames are vertically offset per frame to align their visible pixels to the combat floor and remove the floating effect.
- Existing Zombie scratch attack, pre/post pose, and walking artwork are otherwise unchanged.
