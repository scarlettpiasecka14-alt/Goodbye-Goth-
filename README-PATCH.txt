GOODBYE GOTH — LOADING BAT, ARTWORK SIZE & INVENTORY GRID PATCH
Target: Testing4 branch, applied on top of the existing Screen Polish Patch.

WHAT THIS PATCH DOES
- Shows one complete loading-bat illustration while the Level 1 gate cutscene video is loading.
- Gently floats the whole illustration; no separate sprite frames or complex animation.
- Fades the artwork away when video playback begins.
- Keeps the existing PLAY CUTSCENE fallback and genuine playback-failure message.
- Enlarges the encounter, completion, knockout, and Heavy Attack artwork by approximately 10% on desktop and proportionally on small screens.
- Restores an inventory made of ten visible item boxes in a 5-by-2 grid, with the Golden Key highlighted in its slot.
- Preserves the existing inventory contents, count, save data, item logic, and close-button behaviour.

FILES TO REPLACE / ADD
- Replace: css/screen-polish.css
- Replace: js/screen-polish.js
- Add: assets/story/loading-bat.webp

INSTALL
1. Unzip this patch into the project root, preserving folder paths.
2. Replace the two existing screen-polish files when prompted.
3. Add the new WebP asset at assets/story/loading-bat.webp.
4. Commit to Testing4 only and test the gate cutscene, an encounter/completion screen, knockout, Heavy Attack reward, and inventory.

NOT CHANGED
- js/game.js and js/levels/level1.js are not replaced or edited.
- No combat, challenge, map, progression, item, or save/load logic is changed.
- The inventory redesign is CSS only and uses the existing ten slots generated by the game.

CHECKS
- JavaScript syntax checked.
- CSS parsing checked.
- WebP alpha channel verified; file is roughly 0.38 MB.
- Live browser rendering and cutscene playback must still be verified in the Testing4 deployment.
